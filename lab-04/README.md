\# Лабораторна робота №4. Безперервна інтеграція



\## 1. Мета роботи



Налаштувати локальне середовище для запуску проєкту Wishlist, перевірити взаємодію frontend і backend, а також підготувати проєкти до використання засобів безперервної інтеграції (CI).



\## 2. Структура проєкту



Проєкт складається з двох частин:



\- \*\*wishlist-api\*\* — серверна частина на FastAPI.

\- \*\*wishlist-ui\*\* — клієнтська частина на Vue 3.



Для роботи також використовуються PostgreSQL для зберігання даних і Redis для кешування.



\## 3. Використані технології



| Компонент | Технології |

|---|---|

| Backend | Python, FastAPI, SQLAlchemy |

| Frontend | Vue 3, Vite, TypeScript |

| База даних | PostgreSQL |

| Кешування | Redis |

| Контейнеризація | Docker, Docker Compose |



\## 4. Вимоги до середовища



Для запуску проєкту необхідно встановити:



\- Docker Desktop із підтримкою Docker Compose;

\- Node.js та npm;

\- Git.



\## 5. Запуск backend



Перейти до каталогу API:



```powershell

cd withlist-api

```



Створити локальний файл налаштувань на основі прикладу, якщо `.env` ще не існує:



```powershell

Copy-Item .env.example .env

```



У файлі `.env` потрібно налаштувати секретний ключ та інші параметри середовища. Реальні секрети не потрібно додавати до репозиторію.



Для Docker-оточення адреса Redis повинна бути:



```env

REDIS\_URL=redis://redis:6379

```



Запустити API, PostgreSQL та Redis:



```powershell

docker compose up --build -d

```



Перевірити стан контейнерів:



```powershell

docker compose ps

```



Перевірити доступність API:



```text

http://localhost:8000/health

```



Документація API доступна за адресою:



```text

http://localhost:8000/docs

```



\## 6. Запуск frontend



Відкрити друге вікно PowerShell і перейти до каталогу frontend:



```powershell

cd wishlist-ui

```



Створити локальний файл налаштувань, якщо його ще немає:



```powershell

Copy-Item .env.example .env

```



Встановити залежності:



```powershell

npm install

```



Запустити клієнтську частину:



```powershell

npm run dev

```



Після запуску frontend доступний за адресою:



```text

http://localhost:5173

```



Frontend використовує адресу backend, задану параметром `VITE\_API\_BASE` у файлі `.env`.



\## 7. Перевірка роботи



Для перевірки необхідно:



1\. Переконатися, що контейнери PostgreSQL, Redis та API запущені.

2\. Відкрити frontend у браузері.

3\. Зареєструвати користувача або увійти в систему.

4\. Перейти до розділу списків бажань.

5\. Перевірити отримання та створення даних через API.

6\. Переконатися, що API відповідає на запит `/health`.



\## 8. Зупинка проєкту



Щоб зупинити frontend, натиснути `Ctrl + C` у його терміналі.



Щоб зупинити Docker-контейнери, перейти до каталогу API та виконати:



```powershell

docker compose stop

```



\## 9. Безпека конфігурації



Файли `.env` містять локальні налаштування та секретні значення, тому не повинні публікуватися в репозиторії.



Для прикладу налаштувань використовуються файли `.env.example`, які не повинні містити справжніх паролів або секретних ключів.
