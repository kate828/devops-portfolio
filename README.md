Моя мета — поєднати наявний досвід розробки з практичними навичками DevOps. Прагну навчитися автоматизувати процеси розгортання, будувати надійні CI/CD конвеєри, працювати з Linux, контейнерами та хмарною інфраструктурою, щоб забезпечувати швидку та безпечну доставку програмних продуктів і підготуватися до позиції Junior DevOps Engineer.
